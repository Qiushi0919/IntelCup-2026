# 智驭低空枢纽 · 项目网站

这是 2026 Intel Cup Embedded AI Track 项目网站分支，用于展示作品简介、设计报告、系统截图和演示视频入口。

## 在线访问

- 项目网站：https://qiushi0919.github.io/IntelCup-2026/

## 文件说明

- `index.html`：网站单页入口
- `assets/`：网站图片、系统截图和流程图
- `中文报告.pdf`：作品设计报告
- `作品简介.pdf`：作品简介材料

## 演示视频

演示视频不重复存放在 `Website` 分支中，网页会直接引用 `documents` 分支中已由 Git LFS 托管的视频文件：

`复赛-最终提交文件/演示视频-小于512MB.mp4`

这样可以避免 Website 分支重复上传大文件。

## 部署方式

GitHub Pages 使用 `Website` 分支根目录发布。

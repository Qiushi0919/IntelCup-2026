# Intel Cup 2026 · 飞机代码预留分支

本分支用于后续维护飞控、机载视觉和无人机任务代码。

当前已完整导入原始资料目录：

```text
F260-T432/
```

其中包括历史 OpenMV 示例、TI_FMU 工程、飞控源码、固件、说明书及压缩归档。
这些资料主要来自设备或平台提供方，当前以原样归档和技术参考为目的；
正式开发前应先确认具体飞机型号、飞控版本和各模块授权范围。

## 后续建议结构

```text
aircraft/
  flight_control/     飞控接口与任务状态机
  vision/             机载视觉与火源定位
  communication/      MAVLink、串口或无线数传
  config/             不含密钥的参数模板
  tests/              台架和飞行测试
```

其他分支：

- `ground-station`：地面站与图传代码；
- `documents`：项目方案、进度和参考资料。

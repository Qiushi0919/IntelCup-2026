# 智驭低空枢纽 · 项目网站

这是 2026 Intel Cup Embedded AI Track 项目网站分支，用于展示全国评审版作品简介、软硬件架构、功能完成度、系统截图、演示视频和国赛现场资料。

## 在线访问

- 项目网站：https://qiushi0919.github.io/IntelCup-2026/

## 文件说明

- `index.html`：网站单页入口
- `assets/`：网站图片、系统截图和流程图
- `assets/nationals/`：国赛 PPT 提取图、测试结果、海报、团队合照和国赛演示视频
- `assets/nationals/demos/`：由答辩 PPT 功能动图优化而来的网页循环演示视频
- `中文报告.pdf`：作品设计报告
- `作品简介.pdf`：作品简介材料

## 演示视频

网页默认播放压缩优化后的国赛演示视频：

`assets/nationals/national-finals-demo.mp4`

页面中的“国赛新版 / 复赛旧版”切换可回看旧版完整演示；复赛视频仍引用 `documents` 分支中由 Git LFS 托管的文件。

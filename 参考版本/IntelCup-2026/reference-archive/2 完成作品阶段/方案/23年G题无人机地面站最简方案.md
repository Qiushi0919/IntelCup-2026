# 23年电赛G题无人机与地面站最简方案

## 1. 方案目标

本方案用于使用中科浩电 F260 无人机完成 2023 年全国大学生电子设计竞赛 G 题中与无人机相关的部分。

本方案只考虑：

- 使用 F260 无人机作为空中平台；
- 使用 Intel DK-2500 板卡作为地面站；
- 完成无人机自动巡航、坐标回传、轨迹显示、航程统计、返航降落；
- 不做消防车相关结构、控制、寻路和灭火功能。

最简单可落地目标是：先保基本要求，不优先做投放灭火包、消防车协同和复杂火源识别。

## 2. 总体思路

采用“原飞控稳定飞行 + 地面站下发任务 + 无线数传回传状态”的方案。

F260 无人机保持原有飞控系统，不建议一开始做飞控二次开发。地面站使用 Intel DK-2500 运行 Mission Planner 或自制简化地面站界面，通过无线数传与无人机飞控通信。

无人机端主要补充室内定位和任务展示硬件，包括光流模块、测距模块、下视激光笔和全包桨保护罩。地面站端主要负责显示实时坐标、航迹和累计航程。

## 3. 系统组成

| 模块 | 主要作用 |
|---|---|
| F260 无人机 | 执行起飞、定高、巡航、返航、降落 |
| 原机飞控 | 姿态稳定、航点飞行、飞行模式切换 |
| 光流模块 | 在室内无 GPS 环境下辅助水平定位 |
| 测距模块 | 提供对地高度，用于定高和光流融合 |
| 下视激光笔 | 在地面显示无人机巡航轨迹点 |
| 无线数传 | 无人机与地面站之间传输 MAVLink 数据 |
| Intel DK-2500 | 地面站主机，显示坐标、航迹、航程和任务状态 |
| 遥控器 | 人工接管、安全解锁、应急返航/降落 |

## 4. 推荐飞行任务

场地图尺寸按题目附图理解为 `48 dm x 40 dm`。无人机巡航覆盖宽度按 `8 dm` 设计，因此采用横向“割草式”航线最简单。

推荐航点如下，单位为 `dm`：

| 序号 | 坐标 |
|---|---|
| 1 | `(4, 4)` |
| 2 | `(44, 4)` |
| 3 | `(44, 12)` |
| 4 | `(4, 12)` |
| 5 | `(4, 20)` |
| 6 | `(44, 20)` |
| 7 | `(44, 28)` |
| 8 | `(4, 28)` |
| 9 | `(4, 36)` |
| 10 | `(44, 36)` |
| 11 | 返回起飞区 |

实际调试时，航线可以整体向内缩小，避免靠近边界、障碍物和起飞区边缘。

推荐飞行参数：

| 参数 | 建议值 |
|---|---|
| 巡航高度 | `18 dm` 左右 |
| 飞行速度 | 低速，优先稳定 |
| 坐标回传频率 | 不低于每秒 1 次 |
| 起飞/降落方式 | 自动为主，遥控器随时可接管 |
| 安全策略 | 低电量、数传丢失、定位异常时人工接管或返航 |

## 5. 地面站功能

最简地面站只需要实现以下功能：

| 功能 | 说明 |
|---|---|
| 连接无人机 | 通过 USB 数传连接飞控 |
| 显示实时坐标 | 每秒显示无人机当前位置 |
| 显示飞行轨迹 | 在二维场地图上画出历史轨迹 |
| 显示累计航程 | 根据坐标变化累加飞行距离 |
| 启动/停止任务 | 一键开始巡航，必要时停止任务 |
| 状态显示 | 显示连接状态、飞行模式、电量、定位状态 |

如果时间紧，可以直接使用 Mission Planner 完成航点规划、状态查看和轨迹显示；自制地面站界面可以作为后续优化。

## 8. 调试顺序

建议按以下顺序推进，避免一开始把难度堆满：

1. 单独调通 F260 手动飞行和遥控器接管。
2. 使用 Mission Planner 连接飞控，确认数传链路稳定。
3. 调通光流和测距模块，确认室内定高和水平定位稳定。
4. 设置低速短航线，测试起飞、定高、航点飞行、降落。
5. 加入完整割草式航线，检查是否覆盖全场。
6. 在 DK-2500 上显示实时坐标、轨迹和累计航程。
7. 加装下视激光笔，确认巡航轨迹可见。
8. 最后再考虑火源识别、投放等发挥项。

## 9. 风险与建议

| 风险 | 建议 |
|---|---|
| 室内无 GPS，定位不稳定 | 必须补充光流和测距，不建议只靠飞控惯性估计 |
| 无人机靠近边界或障碍物 | 航线整体内缩，低速飞行 |
| 数传中断 | 遥控器保持开机，设置可人工接管 |
| 外设供电不稳 | 使用独立 5V BEC，不要随意从飞控弱电口取大电流 |
| 机身负载过重 | 只装必要模块，摄像头/投放机构放到后续阶段 |
| 调试摔机 | 先装全包桨保护罩，低高度、低速度测试 |

## 10. 最终推荐版本

第一版只做：

- F260 自动起飞；
- 按割草式航线巡航；
- 每秒回传坐标；
- DK-2500 显示坐标、轨迹、累计航程；
- 无人机下视激光显示巡航点；
- 自动返航降落；
- 遥控器随时人工接管。

这个版本结构最少、调试链路最短，最适合先把题目的无人机基本功能跑通。

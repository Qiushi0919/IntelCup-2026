# Intel Cup 2026 · 文档分支

本分支集中保存“智驭低空枢纽”项目的方案、交接、进度和参考资料。

## 目录

```text
project-documents/   当前项目整理后的总结、方案、交接和进度文档
reference-archive/   原 OneDrive 项目目录中的全部参考文档与配图
```

`reference-archive/` 保留原始目录结构，包含：

- 初赛报名与设计方案；
- 功能汇总、图传和数传方案；
- DK-2500、F260-T432 和无人机相关说明书；
- 阶段进度、截图和参考网页存档；
- 2023 G 题相关资料；
- AMB82-Mini 早期使用说明。

大型软件安装包、驱动、压缩包和视频不属于“参考文档”，没有放入该分支，
仍保留在原始 OneDrive 目录中。

## 其他分支

- `ground-station`：地面站、图传和火源识别代码；
- `aircraft-code`：F260-T432 飞机代码与原始开发资料。

仓库为竞赛项目私有资料库，未附开放许可证。

# 智驭低空枢纽 · 地面站 UI 原型

这是项目的可运行地面站 UI。默认使用模拟无人机数据，可连接
AMB82-Mini 无线相机，并在实时图传中运行火源和人脸目标识别。

## 已包含

- 摄像头主窗口、实时红色 blob 框选和连续帧进度显示；
- 实时广角镜头桶形畸变校正，支持开关与 35% / 50% / 65% 三档调节；
- K230 LAB 颜色识别例程移植，以及亮红模拟火源兼容；
- 大面积红色 blob 连续 20 帧确认，减少小目标和单帧误报；
- 主画面“火源目标识别”开关，默认关闭，开启后才执行实时检测；
- 主画面“人脸目标识别”开关，实时标记 Lucy、Mark、陌生人及置信度；
- 人脸识别使用独立后台线程，只处理最新图传帧，不阻塞相机读取；
- 内置火源测试图和识别结果示例；
- 视频内容固定按 16:9 显示，不随窗口比例拉伸；
- 无人机状态和电池、姿态、光流、链路信息；
- 设备健康状态、任务地图与最近事件摘要；
- 2023 G 题场地与割草式航线；
- 自动起飞、巡逻、暂停、继续、返航、降落的安全命令中心；
- 检测框命中测试、目标悬停高亮，以及“待确认 / 已确认 / 已取消”候选状态闭环；
- 适配 1920×1080、1440×900 和 1366×768 的响应式布局；
- 小于 1200 px 宽度时显示紧凑状态条；低高度时告警折叠但不会消失；
- 语音、手势、视线三个独立可停靠窗口，并可分别启用或禁用；
- 目标事件中心；
- 系统日志；
- 设备与网络设置窗口；
- 模拟飞行、目标发现、低电和任务状态变化；
- 可选接入 `pc_camera_viewer/amb82_camera.py`。

## 启动

双击：

```text
start_ground_station.bat
```

或在工作区运行：

```powershell
python ground_station\main.py
```

## 连接 AMB82-Mini

主界面点击“连接 AMB82”，程序会自动尝试已配置的相机地址。也可以在顶部“设备”窗口中填写：

```text
auto
```

`auto` 会优先搜索新的 720p RTSP 图传；若开发板仍运行旧固件，则自动回退到快照模式。也可以直接填写 RTSP 地址：

```text
rtsp://172.25.135.2:554
```

或旧固件的完整快照地址：

```text
http://172.25.135.2/snapshot.jpg
```

然后点击“测试并连接 AMB82”。

如果设备未开机、电脑不在同一网络或地址不可达，界面会保留明确标注的离线占位画面，并持续显示重连次数、最近错误与连接状态，不会退出程序。

当前方案 C 的图传参数为 `1280×720 / 15 FPS / H.264 / 约 2 Mbps`。地面站显示完整 720p 画面，每个有效图传帧都会在 640 像素宽的缩小副本上执行红色 blob 检测，再将检测框准确映射回主画面。

设备面板中的“镜头校正”默认开启，强度为 50%（中档）。拖动条提供 35%（轻）、50%（中）、65%（强）三档并自动吸附。若画面边缘仍向外鼓起可调至 65%；若直线向内弯曲则降至 35%。正式比赛前建议使用棋盘格完成一次相机标定，以替换当前经验参数。

## 查看火源识别效果

无需连接无人机，点击图传工具栏中的“识别示例”即可加载 K230 红色
blob 诊断画面。画面包含一个足够大的红色模拟火源和若干会被过滤的小红点。
实时图传中连续命中 20 帧后才会确认为火源。示例画面会始终显示
“离线 DEMO · 非实时图传”标识，避免与真实相机画面混淆。

双击真正的检测框才会建立候选目标；双击空白区域只会提示未命中。
候选目标必须在下方状态卡中确认或取消，处理结果会同步写入事件中心。

## 快捷键

- `C`：连接相机；
- `F` / `F11`：切换全屏；
- `Space`：暂停并悬停；
- `Esc`：取消当前候选；
- `M`：打开状态与地图；
- `Ctrl+S`：保存当前截图。

示例文件：

- `examples/competition_map_original.png`：竞赛原始场地图；
- `examples/k230_red_blob_input.png`：K230 红色 blob 诊断输入图；
- `examples/k230_red_blob_result.png`：连续 20 帧确认后的识别结果。

重新生成示例：

```powershell
python ground_station\create_fire_demo.py
```

算法原理、参数和限制见 [FIRE_DETECTION.md](FIRE_DETECTION.md)。

## 使用人脸识别

连接 AMB82 图传后，点击“人脸目标识别：关”将其切换为“开”。地面站会
在中心画面用绿色框标记 Lucy、Mark，用黄色框标记陌生人，并显示置信度。
关闭开关后将立即停止人脸推理并清除画面中的人脸框。

注册图片和本机推理模型位于 `assets/face_recognition/`。如需替换注册人脸，
替换 `lucy.png` 或 `mark.jpg` 后重新启动地面站即可自动重建特征。

## 当前限制

- 飞控数据来自模拟器，尚未连接真实 MAVLink/串口；
- 当前火源识别只针对足够大的红色模拟物体，不识别真实火焰、烟雾或温度；
- 红色灯光、红色衣物等持续出现的大面积物体仍可能产生误报；
- 语音、手势和视线为交互流程原型，不包含实际识别模型；
- 高风险命令会要求屏幕确认；
- GUI 框架当前使用系统已有的 PyQt5，后续可迁移到 PySide6。

## 主要文件

- `main.py`：主窗口和业务事件；
- `widgets.py`：视频、状态、地图和工具窗口；
- `camera_service.py`：AMB82 图传线程；
- `k230_color_detector.py`：K230 LAB 红色 blob 检测与连续 20 帧确认；
- `face_recognition_service.py`：本机实时人脸检测、特征匹配和后台线程；
- `simulator.py`：无人机状态模拟；
- `models.py`：共享数据结构；
- `styles.py`：界面样式；
- `create_fire_demo.py`：示例图生成与离线验证。

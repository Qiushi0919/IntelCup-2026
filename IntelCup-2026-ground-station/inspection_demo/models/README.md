# Inspection model assets

These small models are kept in the repository so the competition demo can run offline.

- `face-detection-retail-0005.xml/.bin`: OpenVINO Open Model Zoo FP16 model, used on Intel NPU. Source: `https://storage.openvinotoolkit.org/repositories/open_model_zoo/2023.0/models_bin/1/face-detection-retail-0005/FP16/`
- `face_detection_yunet_2023mar.onnx`: OpenCV Zoo YuNet model, used as the CPU fallback.

The generated `.npu_cache` directory is machine-specific and is intentionally not tracked.
